# CSPI-LLM-TIE-Supplementary-Code
Supplementary code for "Physics-Guided Semantic Control of AUVs Using Embedded Language Models for Real-Time Subsea Inspection" (CSPI-LLM, IEEE TIE). Includes teacher distillation, Qwen3-4B+LoRA student LLM, semantic-gated SAC, Isaac Lab/OceanSim validation, and BSA-D2 tank hardware interface.
